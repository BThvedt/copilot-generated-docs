Workspace: Collecting workspace informationFiltering to most relevant informationHere is a summary of all the PHP files in the Block folder:

1. **AAIFooter.php**  
   - Provides a block labeled "AAI Footer."
   - Displays a footer with a link to "August Ash."

2. **AddressInfo.php**  
   - Provides a block labeled "Address Info."
   - Displays the site's address as a renderable element.

3. **AsideToggleBlock.php**  
   - Provides a block labeled "Aside Toggle."
   - Displays a toggle button for an aside menu.

4. **CopyrightInfo.php**  
   - Provides a block labeled "Copyright Info."
   - Displays copyright information with the current year.

5. **DashboardIntro.php**  
   - Provides a block labeled "Dashboard Intro."
   - Displays an introductory message for the dashboard.

6. **DashboardNotice.php**  
   - Provides a block labeled "Dashboard Notice."
   - Displays a global dashboard notification.

7. **GlobalNotification.php**  
   - Provides a block labeled "Global Notification."
   - Displays a global notification (currently disabled in the form).

8. **PhoneInfo.php**  
   - Provides a block labeled "Phone Info."
   - Displays the site's phone number as a renderable element.

9. **SidebarAddressInfo.php**  
   - Provides a block labeled "Sidebar Address Info."
   - Displays the site's address, a map iframe, and a "Get Directions" button.

10. **SocialLinks.php**  
    - Provides a block labeled "Social Links."
    - Displays social media links as a renderable element.
